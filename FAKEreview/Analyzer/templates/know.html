How FRASA Works

From raw review text to intelligent analysis — here's the full picture.

The Process

01

📝 Submit a Review

Paste any product review into the input box. FRASA accepts text of any length and language style.

02

🤖 ML Model Analyzes

Our trained machine learning model scans the review for patterns — over-excitement, repetition, vague language — that signal fake content.

03

🎭 Sentiment is Detected

A separate NLP pipeline classifies the emotional tone as Positive, Negative, or Neutral with a confidence score.

04

📊 Results are Shown

You instantly see whether the review is Fake or Genuine, along with the sentiment breakdown and confidence bars.

05

🗂️ Saved to History

Every analysis is saved to your account so you can review, compare, and track past predictions anytime.

Tech Behind FRASA

🐍 Python & Django

Backend logic and routing powered by Django, keeping everything fast and secure.

🧠 Scikit-learn

Machine learning models trained on labeled review datasets to detect fake patterns.

💬 NLP Pipeline

Natural language processing to break down text and extract sentiment signals.

🗄️ SQLite / PostgreSQL

All review history and user data stored reliably in a relational database.
